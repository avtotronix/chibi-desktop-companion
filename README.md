> **ChibiPet** — интерактивный 3D-чибик на рабочий стол Windows (WPF .NET 8), живущий прямо поверх всех окон. Чибик автономно исследует экран, реагирует на действия, добывает руды и рубит деревья, рыбачит, карабкается по стенам до самого верха монитора и охотится за вашим курсором.

## ✨ Ключевые возможности

### ⛏️ 1. Аутентичная добыча ресурсов (Mining)
- **11 видов деревьев**: Дуб, Берёза, Ель, Тёмный дуб, Бледный дуб, Тропическое, Акация, Мангровое, Вишня, Багровое, Искажённое (с аутентичными текстурами коры и среза).
- **11 видов руд**: Уголь, Железо, Медь, Золото, Лазурит, Редстоун, Алмазы, Изумруды, Кварц Незера, Древние обломки (Незерит), Золото Незера + варианты из глубинного сланца (Deepslate).
- **Инструменты**: Незеритовый топор и незеритовая кирка, ориентированные прямо из кулака персонажа.
- **Динамическое растрескивание**: 4 стадии трещин (0..3) на блоке во время ударов.
- **Осколки и дроп**: Сотрясение блока от отдачи, разлёт осколков и вылетающий вращающийся 3D-лут (слитки, самоцветы, мини-брёвна), притягивающийся к рукам персонажа.

### 🎣 2. Рыбалка с анимацией (Fishing)
- 3D-удочка с катушкой и леской.
- Водная рябь на полу и красно-белый поплавок.
- Случайное время ожидания поклёвки (7–18 с). При поклёвке поплавок резко уходит под воду с брызгами (`💦`).
- Персонаж делает подсечку, и улов по высокой параболе взлетает в воздух!
- **7 видов улова** с индивидуальными реакциями:
  - 🐟 Сырая треска (Радость)
  - 🍣 Сырой лосось (Радость)
  - 🐠 Рыба-клоун (Смущение)
  - 🐡 Иглобрюх (Испуг)
  - 💎 Алмаз (Победный танец)
  - 📖 Зачарованная книга «Починка» (Восторг)
  - 💣 Зажжённый динамит TNT (Шок и паника)

### 🧗 3. Паркур и карабканье на самый верх экрана
- Взбирается по левому и правому краю монитора **до самого верха экрана** (`Bounds.Top`), касаясь верхнего края монитора.
- Зависает у верхнего края, осматривается и совершает акробатический прыжок со стены (`WallJump`) через пол-экрана.

### 🎯 4. Интерактивная игра с курсором
- **Преследование**: бежит за курсором по экрану.
- **Карабканье за курсором**: если поднять курсор вверх, чибик бежит к стене и карабкается наверх на высоту курсора.
- **Перехват в воздухе**: если отвести курсор в центр экрана, чибик прыгает со стены навстречу курсору.
- **Поимка**: при точном наведении курсора на модельку чибик празднует победу сердечками.

### 🖼️ 5. Динамическая иконка на рабочем столе
- Ярлык приложения на рабочем столе Windows (`ChibiPet.lnk`) автоматически обновляет свою иконку на **лицо текущего скина аватара**!
- Поддерживает системное мгновенное обновление проводника (`SHChangeNotify`).

### 💃 6. Физика и кастомизация (Wildfire's Gender Style)
- Поддержка скинов Steve, Ganyu и любых пользовательских скинов Minecraft (PNG 64x64 и 64x32).
- Настройки физики (гармонический осциллятор с затуханием второго порядка для естественного покачивания при ходьбе, беге и прыжках).

### ⏳ 7. Помощник продуктивности
- Pomodoro-таймер (25 мин работы / 5 мин отдыха).
- Напоминания попить воды и сделать разминку.
- Автоматический сон ночью (после 23:00) и при длительном простое.

## 🛠️ Сборка из исходников (Building)

Требования: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) для Windows.

```bash
# Клонировать репозиторий
git clone https://github.com/avtotronix/chibi-desktop-companion.git
cd chibi-desktop-companion

# Собрать решение
dotnet build ChibiPet.sln -c Release

# Опубликовать автономный исполняемый файл
dotnet publish ChibiPet/ChibiPet.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./Publish
```
